Module 3.1 · Types of Learning & Overfitting Problems
LOS 3.a

Supervised, Unsupervised & Deep Learning

Describe supervised ML, unsupervised ML, and deep learning; ML terminology and algorithm choice.

The statistical models covered so far rely on assumptions about the distribution of the underlying data. Machine learning (ML) requires no such assumptions. ML is the use of algorithms to make decisions by generalizing (finding patterns) in a given data set — "find the pattern, apply the pattern." It performs better than standard statistical approaches when there are many variables (high dimension) and when relationships are nonlinear.

ML terminology

Target variable

The dependent variable (the y variable). Can be continuous, categorical, or ordinal.

Features

The independent variables (the x variables).

Training dataset

The sample used to fit the model.

Hyperparameter

A model input specified by the researcher (not learned from the data), e.g., k in KNN/k-means, λ in LASSO.

Three families of ML (slide overview)

Supervised learning

Uses labeled training data (target variable is defined) to guide the program toward better forecasts.

Unsupervised learning

Features are given without labels/conclusions; the program finds structure on its own.

Reinforcement learning

The program learns from its own output and prediction errors, seeking to maximize a reward.

Supervised learning

Example: to identify earnings manipulators, supply many attributes for known manipulators and known non-manipulators; the program learns patterns to flag manipulators in a new data set. Multiple regression is itself a supervised learning method. Two typical tasks:

TaskTarget variableExamples
RegressionContinuous (numeric label)House-price prediction
ClassificationCategorical or ordinal (e.g., a ranking)Binary: likely to default vs. not. Multicategory: bond ratings class

Unsupervised learning

No labeled training data and no target variable: inputs (features) are provided without any conclusions. The program seeks structure or interrelationships in the data. Clustering is the standard example.

Deep learning and reinforcement learning

Deep learning algorithms handle complex tasks such as image recognition and natural language processing; they are built on neural networks (ML algorithms for problems with significant nonlinearities) and learn from a training set, then apply that learning to new data. Programs that learn from their own output and prediction errors are reinforcement learning algorithms.

Slide analogy — reinforcement learning
A dog fetching a ball: the dog = learning algorithm/agent; the environment = where you and the dog play; the action = fetching the ball; the reward = the treat (positive if fetched; perhaps nonexistent, or even negative, if not).

LOS 3.b

Overfitting and How to Address It

Describe overfitting and identify methods of addressing it.

Overfitting is an issue with supervised ML that arises when a large number of features is included. The model treats noise as pattern (randomness misperceived as signal), giving a high in-sample R², but forecasts on other data are less accurate: overfit models do not generalize (low out-of-sample R²).

Professor's Note
A model that generalizes well retains its explanatory power when applied to new (out-of-sample) data.

Three nonoverlapping data sets

Training sample

Used to develop (fit) the model.

Validation sample

Used for tuning the model.

Test sample

Used to evaluate the model on new data (e.g., 80% train / 20% test, or train / validation / test).

Prediction errors in the training and validation samples are in-sample errors; errors in the test sample are the out-of-sample error.

Three types of error

Bias error

In-sample error from a model with a poor fit (underfitting).

Variance error

Out-of-sample error from an overfit model that does not generalize.

Base error

Residual error due to random noise; cannot be removed.

Error decomposition
Out-of-sample error = bias error + variance error + base error

Learning curves (Figure 3.3, redrawn)

A learning curve plots the accuracy rate (1 − error rate) in the validation/test sample against the size of the training sample.

PatternIn-sample accuracyOut-of-sample accuracyDiagnosis
High bias errorConverges, but far below the desired levelConverges to the same low levelUnderfit — too simple
High variance errorConverges toward the desired levelLags far behind in-sampleOverfit — does not generalize
Robust (good fit)Improves toward desired levelImproves and converges with in-sample at the desired levelWell generalizing

Complexity trade-off

Variance error rises with model complexity; bias error falls. Linear models tend to have high bias error; nonlinear models tend to have high variance error. This is the trade-off between cost and complexity. An optimal complexity minimizes total error and is key to generalization. Slide illustration: underfit (too-simple boundary), overfit (wiggly boundary fitting noise), good fit.

Remedies for overfitting

Complexity reduction

A penalty excludes features that do not meaningfully contribute to out-of-sample accuracy; the penalty increases with the number of features used.

Cross validation

Estimates out-of-sample error directly from the validation sample. Training and validation data must be large and representative of the population.

k-fold cross validation

Randomly divide the sample equally into k parts. Training uses (k − 1) parts, with one part left for validation. Error is measured, and the process is repeated k times (each part serves once as the validation fold); the average in-sample and out-of-sample error rates are compiled. In 5-fold validation, iterations 1st–5th each hold out a different fold.

k-fold performance
Performance = (1/k) × Σ Performancei
i = 1 … k folds
Key Concepts — LOS 3.b
Overfitting = too many features → overly complex model that generalizes noise (high in-sample, low out-of-sample accuracy). Fix with complexity reduction (penalty on features) and cross validation.

Module 3.2 · Supervised Learning Algorithms
LOS 3.c

Supervised Learning Algorithms

Penalized regression, SVM, KNN, CART, ensemble learning and random forest, and the problems each suits.

1. Penalized regression and LASSO

A form of linear regression that penalizes the size of the coefficients to reduce overfitting and manage multicollinearity. The penalty increases with the number of features, so features that do not contribute to out-of-sample accuracy are excluded (more parsimonious model). The model minimizes SSE plus a penalty.

LASSO (least absolute shrinkage and selection operator): in addition to SSE, it minimizes the sum of the absolute values of the slope coefficients. There is a trade-off between lowering SSE (more features) and the penalty for including them; optimization automatically eliminates the least predictive features. The penalty term λ (lambda) is the hyperparameter balancing overfitting against parsimony.

LASSO objective
Minimize Σ(Yi − Ŷi)2 + λ Σ|bj|
Σ(Y − Ŷ)² = SSE; λ = penalty hyperparameter; bj = slope coefficients.

Regularization forces the beta coefficients of nonperforming features toward zero; it reduces statistical variability in high-dimension estimation and can be applied to nonlinear models (e.g., a stable covariance matrix for mean-variance optimization). Slide steps: (1) find the model minimizing SSE, (2) calculate SSE, (3) apply λ and recompute the error, (4) find the new model minimizing the new error.

Professor's Note
Parsimonious in statistics: a model that achieves the required explanation with as few predictor variables as possible (not "stingy").

2. Support vector machine (SVM)

A linear classification algorithm that separates data into one of two possible classes (e.g., sell vs. buy). With n features, an n-dimensional hyperplane divides the sample. SVM chooses the boundary farthest from all observations: a discriminant boundary plus margins on either side. The margins are set by the support vectors (observations closest to the boundary). Misclassified training observations are handled by soft margin classification, which optimizes the trade-off between a wider margin and classification error. A more complex nonlinear model can cut classification error but needs more features and risks overfitting.

SVM decision rule (slide)
f(x1,x2) = w1x1 + w2x2 + b
Boundary: f = 0. Class 1 if f > 0; class 0 if f ≤ 0.

Applications: classifying debt issuers as likely vs. not likely to default, stocks to short vs. not, and text (news, press releases) as positive vs. negative.

3. K-nearest neighbor (KNN)

Classifies an observation by its nearness to observations in the training sample; more common in classification, sometimes regression. The researcher specifies k (hyperparameter); the algorithm finds the k closest observations to the new one.

k too small

High error rate.

k too large

Dilutes the result by averaging across too many outcomes.

k even

Ties are possible, with no clear winner.

KNN is a powerful nonparametric model (no assumptions about data distribution), but you must define "near": analysts need to understand the data and business to specify the distance metric. Irrelevant or correlated features can skew results. Slide: shuffle and randomly divide into k sub-samples, k − 1 for training and 1 for validation. Applications: predicting bankruptcy, assigning a bond to a ratings class, predicting stock prices, creating customized indices.

4. Classification and regression trees (CART)

Classification trees suit a categorical target, typically binary (IPO successful vs. not). Regression trees suit a continuous target. Logit models also handle binary targets but are ill-suited to significant nonlinear relationships, where trees are an alternative. At each node the tree splits observations in two: the top feature (most important for the target) is chosen with a cutoff c; observations above c go to one class, the rest to the other; classes are then split on a second feature. Each split should lower estimation error; the tree stops when error cannot be reduced, at a terminal node. A feature may reappear lower in the tree with a different cutoff. Features and cutoffs are learned from labeled training data.

Figure 3.4 — Classification tree (redrawn as text)
Root node → 2 decision nodes → each decision node splits into a decision node and a terminal node → lower decision nodes end in 2 terminal nodes each
Root node = first (top-feature) split; decision nodes = further splits; terminal nodes = final classifications.

Avoiding overfitting: researcher-set regularization criteria (maximum tree depth, maximum number of decision nodes) or pruning sections with minimal explanatory power. CART is popular because it gives a visual explanation of the prediction process (unlike "black box" algorithms). Applications: detecting fraudulent financial statements; selecting stocks and bonds.

5. Ensemble learning and random forest

Ensemble learning combines predictions from multiple models rather than one; the result is a lower average error rate because models cancel out noise (more accurate and stable).

Heterogeneous learners

Different algorithms combined via a voting classifier; each votes and the majority wins. Diversity of approach gives greater confidence.

Homogeneous learners

Same algorithm on different training samples, derived by bootstrap aggregating (bagging): random samples (bags) drawn with replacement from the initial training sample.

Random forest is a variant of classification trees: a large number of trees trained on bagged data from the same data set, each using a randomly selected subset of features, so every tree differs. Using many trees to decide the final class is akin to crowdsourcing. Because each tree uses only a subset of features it mitigates overfitting; errors across trees tend to cancel, raising the signal-to-noise ratio. Drawback: the transparency of CART is lost — back to a black box. Applications: factor-based asset allocation; predicting IPO success.

Module 3.3 · Unsupervised Learning Algorithms & Other Models
LOS 3.d

Unsupervised Algorithms, Neural Nets & Deep Learning

PCA, k-means, hierarchical clustering, plus neural networks, deep learning networks and reinforcement learning.

1. Principal components analysis (PCA)

Too many features (high dimension) create noise. Dimension reduction discards attributes that carry little information. PCA summarizes a large number of correlated factors into a much smaller set of uncorrelated factors called eigenvectors — linear combinations of the original features (PCA1 = a1X1 + b1X2 + …). Each eigenvector has an eigenvalue: the proportion of total variance explained. The factor with the highest eigenvalue is the most important, then the second-highest, and so on, up to the number the researcher specifies.

A scree plot shows the proportion of total variance explained by each principal component (highest to lowest; the "elbow" marks where gains flatten). In practice, retain the smallest number of components that together capture 85%–95% of total variance. Because components are linear combinations of the original data, they cannot be easily labeled or interpreted → black-box.

2. Clustering

Groups observations into categories based on similarity of attributes (cohesion) — e.g., classify stocks by past performance instead of sector. Human judgment defines "similar." A common metric is Euclidean distance (straight-line distance between two observations).

2.1 K-means clustering

Partitions observations into k nonoverlapping clusters; k is a hyperparameter set before clustering. Each cluster has a centroid (its center) and each observation is assigned by proximity to a centroid.

Pick k; randomly place k centroids
→
Assign each point to its closest centroid
→
Recompute each centroid
→
Reassign points to the new nearest centroid; repeat until no reassignment

Limitation: k must be chosen up front, so you need some idea of the data's nature. Use: classify thousands of securities from patterns in high-dimensional data.

2.2 Hierarchical clustering

Builds a hierarchy of clusters without a predefined number of clusters.

Agglomerative (bottom-up)

Start with each observation as its own cluster; merge the closest (most similar) clusters step by step.

Divisive (top-down)

Start with one giant cluster and partition it into smaller and smaller clusters.

Investment uses: diversify by holding assets from multiple clusters; analyze portfolio risk — concentration shows as a large allocation to one cluster. Clusters are not clearly labeled, but clustering uncovers hidden structure.

Example — ML for ESG investing
Governance is objectively measurable; social/environmental impact is subjective. NLP can parse corporate disclosures (text, audio, video): words like "human capital," "living wage," "D&I" proxy social responsibility; "sustainable," "recycle," "green" proxy environmental intent. Supervised algorithms (logistic regression, SVM, CART, random forests, neural networks) then generate ESG scores.

Neural networks (NNs / ANNs)

Used for supervised regression and classification; nodes connected by links in three kinds of layers:

Input layer

One node per feature; values are scaled so they are comparable for weighted averaging.

Hidden layer(s)

Nodes called neurons: a summation operator (weighted average) feeding a typically nonlinear activation function; output passes to the next layer.

Output layer

Typically a single node — the model's prediction.

Forward propagation passes values forward through the layers; backward propagation revises the weights in the summation operators as the network learns from its errors. Multiple hidden layers with their own activation functions let NNs model complex nonlinear functions. The researcher sets the structure: e.g., 3 inputs, one hidden layer of 4 nodes, 1 output → (3, 4, 1), the network's hyperparameters, revisable based on out-of-sample performance.

Deep learning networks (DLNs)

Neural networks with many hidden layers — at least 2, often more than 20. Used for image, pattern, speech and character recognition; the last layer gives the expected probability of belonging to each category and the observation goes to the highest. Further uses: credit card fraud detection, autonomous cars, NLP, investment decisions. One study using the six Black-Scholes inputs predicted option values with R² of 99.8%; others used standard factors (book-to-market, operating income/market cap) to beat factor models. Popularity stems from better analytics, faster computing and large machine-readable data.

Reinforcement learning (RL)

An agent seeks to maximize a defined reward under defined constraints. It uses no labeled training data and gives no instantaneous feedback; it learns from millions of trials. DeepMind's AlphaGo beat the reigning Go world champion. Its efficacy in investment decisions is not yet conclusive.

Key Concepts — LOS 3.d
PCA (uncorrelated eigenvectors), k-means (k nonoverlapping clusters, centroids), hierarchical (no predefined clusters). NNs = input, hidden (neurons: summation + activation), output. DLNs = multiple hidden layers (image/speech/pattern recognition). RL = learn from own errors to maximize reward.
